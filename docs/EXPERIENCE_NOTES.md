# تجربة Lunar Relics 3D

## ما تغيّر

الدخول الأول خفيف ولا ينشئ مشهد WebGL أو يحمّل مجسمات المركبات خلف شاشة البداية. يبدأ الاستكشاف من إيغل أو الأرشيف أو أحد العوالم الثلاثة، والصوت مغلق افتراضيًا واختياري. تُحفظ اللغة والصوت والشارات والتقدم دون حذف مفاتيح المستخدم القديمة.

الأرشيف يوضح طريق التعلم: اختر مهمة، اقرأ القصة وافحص الأجزاء، ثم أجب عن السؤال. أزرار اللمس أوضح، والبحث يتيح الرجوع إلى جميع المهمات، والمشاركة تنسخ رابط المهمة بلغتها. مثال: `?mission=insight-lander&lang=ar`؛ وللعوالم `?view=Mars`.

يحافظ عرض InSight على الكادر المرتفع الثلاثي الأرباع وإضاءة التفاصيل، مع احتواء عرض الألواح على الشاشة الضيقة. لم تتغير ملفات GLB أو بيانات المهمات أو خدمة API أو اللودر الأساسي.

## مصادر السماء والأرض والمركبات

- **القمر:** [NASA CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/)، خرائط لون LROC وارتفاع LOLA، برصيد NASA’s Scientific Visualization Studio. NASA توضح أن خرائط اللون معدّة للتصوير الجمالي، لا للقياسات العلمية. خامة معاينة البداية من الخامة المحلية نفسها وليست تضاريس مختلقة.
- **المريخ:** [فسيفساء Viking MDIM 2.1 من USGS/NASA Ames](https://astrogeology.usgs.gov/search/map/mars_viking_colorized_global_mosaic_232m). المصدر فسيفساء ملوّنة فنيًا، وليس خريطة ارتفاع؛ لا نحول اللون إلى إزاحة تضاريس علمية مزعومة.
- **InSight:** [النموذج الرسمي](https://science.nasa.gov/resource/insight-lander-3d-model/)، برصيد NASA/JPL-Caltech. ملف التشغيل المشتق 2,957,580 بايت؛ رابط أصل NASA والرصيد محفوظان في [مصادر النماذج](../public/models/ASSET_SOURCES.md).
- **بقية المركبات:** [مركز موارد NASA ثلاثية الأبعاد](https://science.nasa.gov/3d-resources/). يميز الموقع بين المجسم المنشور وإعادة البناء التوضيحية؛ لا يدّعي أن كل مجسم ملف NASA مطابق، ولا أن NASA تؤيد المشروع.

الإضاءة وكادرات الكاميرا وسائل عرض تعليمية، وليست محاكاة لتاريخ الشمس أو أدوات تحديد مواقع ميدانية دقيقة. إحداثيات المهمات والبيانات الأصلية محفوظة كما هي.

## الأداء وحدود القياس

الهدف تجربة قريبة من 60 إطارًا/ثانية، وليس ضمانًا على كل هاتف. الجودة تتكيف مع إطارات Canvas المقاسة فعليًا، مع سقف DPR أقل للهاتف، هندسة كواكب ونجوم أخف، وإلغاء ContactShadows على الشاشات الضيقة أو الجودة المنخفضة. يتوقف الرسم عند إخفاء التبويب، وتُحترم إعدادات تقليل الحركة.

لإظهار قياس فعلي اختياري أضف `&perf=1` إلى رابط المهمة أو العالم. المؤشر يعرض متوسط نافذة ثلاث ثوانٍ بعد الإحماء، وعدد draw calls والمثلثات وDPR؛ لا يقيس زمن الشبكة ولا يمثل اختبار هاتف حقيقي. نتيجة جلسة المتصفح السحابية وحدها لا تثبت تحقيق 60 FPS.

## التحقق

شغّل `npm test` لاختبارات الروابط والتفضيلات وبصمات 13 ملفًا محميًا، وربط InSight وتوثيق مصدره واستبعاد أصله الكبير. شغّل `npm run build` لبناء الإنتاج. بقاء الملفات القديمة محفوظة يعني أن مجموع أصول المستودع ليس هو حجم تنزيل صفحة الدخول؛ المجسمات تُحمّل عند اختيارها.
